# 上班模擬器（暫名）設計文件

> 版本：草稿 v0.1 ・ 最後更新：2026-10-16
> 本文件是開發的唯一規格。實作與文件不一致時，先討論再決定改哪一邊。

---

## 1. 一句話介紹

一款手機優先的放置型人生經營遊戲：從 22 歲新鮮人開始上班，薪水自己會進帳，你要決定**下班後的時間**怎麼用，一路轉職、進修、交朋友、談戀愛，直到退休或財富自由。

## 2. 設計支柱

這三條是判斷「這個功能該不該做、該怎麼做」的依據。

1. **時間是最稀缺的資源**
   所有系統都在搶同一份「下班後的時間與體力」。每個選擇都要有代價，沒有永遠正確的答案。
2. **放著也會前進**
   打開看一看、做幾個決定、關掉，回來時人生已經往前走了。不需要一直盯著畫面。
3. **真實到會心一笑**
   事件取材自台灣上班族的日常：LINE 群組被 @、年終一個月、「簡單改一下就好」。好笑，但不刻薄。

## 3. 目標玩家與平台

- 目標玩家：上班族、即將出社會的學生，通勤或睡前打開玩幾分鐘
- 平台：手機瀏覽器，直式畫面，以 PWA 形式「加入主畫面」
- 單次遊玩：1～5 分鐘
- 一輪人生（22～65 歲）：約 43 小時的遊戲時間，加上離線推進，依遊玩頻率約 3～6 週完成

## 5. 時間系統

### 5.1 時間尺度

| 項目 | 數值（初始值） |
|---|---|
| 1 遊戲日 | 10 秒真實時間 |
| 1 遊戲週 | 70 秒 |
| 1 遊戲年 | 約 61 分鐘 |
| 22～65 歲 | 約 43 小時 |
| 速度切換 | 暫停／×1／×2／×4 |

遊戲以「日」為最小單位推進。所有系統都在每日結算時處理，離線推進也呼叫同一個函式，這樣結果才會一致。

### 5.2 每週行程（時段）

每週有 **7 個時段**：週一到週五的晚上各一格，週六、週日各一格。

玩家設定一份「每週行程範本」，遊戲會每週自動套用，這就是放置的部分。隨時都可以修改，下一個時段開始生效。

| 時段活動 | 效果 | 開放版本 |
|---|---|---|
| 休息 | 體力 ↑、心情 ↑ | v0.1 |
| 加班 | 加班費、工作表現 ↑；體力 ↓↓、心情 ↓ | v0.1 |
| 耍廢 | 心情 ↑↑，其他不變 | v0.2 |
| 進修 | 依所上課程提升技能；體力 ↓、花費 | v0.2 |
| 運動 | 體力上限 ↑、恢復速度 ↑；花費 | v0.2 |
| 參加活動 | 人脈 ↑、可能認識新朋友（見 §9） | v0.4 |
| 約會 | 好感 ↑、心情 ↑；花費（需有對象） | v0.5 |
| 副業 | 收入 ↑；體力 ↓（需特定技能） | v0.4 |

部分事件會**強制佔用時段**，例如「主管說今晚要加班」，玩家可以選擇接受或拒絕，各有後果。

### 5.3 離線推進

- 離開遊戲時，時間照常推進，最多推進 **12 遊戲週**（約等於 14 分鐘真實時間；離開更久也只推進到這裡，避免一覺醒來人生少了好幾年）
- 遇到**重大抉擇**事件（見 §10.2）時，提早停下來，等玩家回來決定
- 一般事件依「預設選項」自動處理
- 回到遊戲時，先顯示「你不在的時候」摘要：賺了多少、發生了哪些事、數值怎麼變

## 6. 角色數值

| 數值 | 範圍 | 說明 |
|---|---|---|
| 年齡 | 22～65+ | 由遊戲日期推算 |
| 存款 | 不限，可為負 | 新台幣；為負時進入負債狀態並觸發事件 |
| 月薪 | — | 依職位決定，以日薪形式即時進帳（畫面上的數字會持續跳動） |
| 體力 | 0～上限（初始 100） | 上班、加班會消耗；為 0 時病倒 |
| 心情 | 0～100 | 低於 20 時表現下降，並開始觸發「想離職」事件 |
| 工作表現 | 0～100 | 在目前職位累積，用於年度考核；轉職後歸零 |
| 年資 | — | 總工作年數，轉職時保留 |
| 技能 | 每項 0～100 | 專業、外語、管理、程式、溝通（可擴充） |
| 人脈 | NPC 清單 | 見 §9；轉職、內推、活動都會用到 |

### 6.1 狀態門檻

| 條件 | 後果 |
|---|---|
| 體力 < 20 | 工作表現累積速度減半 |
| 體力 = 0 | 病倒：強制請假 1 週、支付醫藥費、心情 ↓ |
| 心情 < 20 | 工作表現累積減半；每週有機率觸發「想離職」事件 |
| 存款 < 0 | 觸發「卡債」事件鏈，每月加收利息 |

## 7. 工作與升遷

### 7.1 每日上班

- 平日自動上班：體力小幅下降，工作表現依體力與心情累積
- 週末不上班（部分產業例外，見 §8.1）

### 7.2 職位階梯（通用）

| 階級 | 職稱範例 | 升遷條件（初始值） |
|---|---|---|
| 1 | 專員 | 起始職位 |
| 2 | 資深專員 | 本職年資 2 年、考核達 B |
| 3 | 主任／組長 | 本職年資 3 年、考核達 B、管理 ≥ 20 |
| 4 | 經理 | 本職年資 4 年、考核達 A、管理 ≥ 40 |
| 5 | 協理 | 本職年資 5 年、考核達 A、管理 ≥ 60、人脈 ≥ 10 |
| 6 | 總經理 | 考核連 3 年 A、管理 ≥ 80（觸發「爬到頂」結局選項） |

「本職年資」是指在目前公司的年資。各產業可以覆寫職稱與條件。

### 7.3 年度考核

每年 1 月 1 日依工作表現評等：

| 工作表現 | 評等 | 結果 |
|---|---|---|
| ≥ 80 | A | 加薪 5～8%，符合條件則升遷 |
| 60～79 | B | 加薪 2～4%，符合條件則升遷 |
| 40～59 | C | 不加薪 |
| < 40 | D | 不加薪；連兩年 D 會觸發「被約談」事件 |

考核結束後，工作表現降為原本的 50%，代表新年度重新累積。

## 8. 轉職（v0.3）

### 8.1 產業

| 產業 | 起薪 | 加薪幅度 | 加班頻率 | 穩定度 | 特色 |
|---|---|---|---|---|---|
| 科技業 | 高 | 高 | 高 | 中 | 有分紅事件；程式技能大幅加成 |
| 公務員 | 中 | 低（固定級距） | 低 | 極高 | 需先考上高普考；不會被裁員 |
| 金融業 | 中高 | 中 | 中 | 中 | 有業績壓力事件；外語、溝通加成 |
| 服務業 | 低 | 低 | 中，含週末班 | 中 | 轉職門檻最低；溝通加成 |
| 新創 | 中 | 不固定 | 極高 | 低 | 有機率倒閉，也有機率因股票暴富 |

v0.3 先做其中 3～4 種，其餘之後補上。

### 8.2 求職流程

1. **看職缺**：職缺板每月刷新，列出 5～8 個職缺，各有產業、職位、薪水、條件
2. **投履歷**：依技能、年資與條件比對，決定是否通過書面審查
3. **面試**：一次面試事件，有 2～3 個選擇，成功率受技能與心情影響
4. **錄取**：選擇是否接受；接受後一個月到職，工作表現歸零

### 8.3 特殊規則

- **內推**：人脈裡有該產業的朋友，而且好感夠高時，可以跳過書面審查
- **年齡門檻**：35 歲後，一般職缺的通過率逐年下降，但人脈內推不受影響
- **裸辭**：可以先離職再找工作。空窗期沒有收入，但每天多出整天的時段可以安排
- **特殊路線**（v0.4 之後）：接案、創業、出國打工度假

## 9. 進修、活動與人際

### 9.1 進修（v0.2）

課程需要先報名付費，之後每週要排入指定數量的「進修」時段。

| 課程範例 | 期間 | 費用 | 每週時段 | 效果 |
|---|---|---|---|---|
| 英文會話班 | 3 個月 | 1.2 萬 | 2 | 外語 +15 |
| 多益檢定 | 2 個月準備 + 考試 | 0.2 萬 | 2 | 考過取得證照；轉職加分 |
| 程式設計入門 | 4 個月 | 2.5 萬 | 3 | 程式 +20，解鎖副業「接案」 |
| PMP 專案管理 | 3 個月 + 考試 | 3 萬 | 2 | 管理 +15，考過取得證照 |
| 在職專班（MBA） | 2 年 | 30 萬 | 2 | 管理 +30、人脈 +5、學歷提升 |

- **出席率**低於 70% 就算失敗，學費不退
- **考試**的通過率依該技能數值與考前的體力、心情決定
- 學費可能遇到「公司補助」事件

### 9.2 參加活動（v0.4）

在時段中選「參加活動」時，要再選活動類型：

| 活動 | 費用 | 主要效果 | 可能遇到 |
|---|---|---|---|
| 讀書會 | 低 | 人脈 ↑、某項技能小幅 ↑ | 各產業的人 |
| 健身房 | 月費 | 體力上限 ↑ | 健身愛好者 |
| 登山社 | 中 | 心情 ↑↑、體力 ↑ | 各種人，偶爾遇到前同事或主管 |
| 聯誼 | 中 | 遇到戀愛對象的機率高 | 單身者 |
| 產業研討會 | 中高 | 人脈 ↑↑，限特定產業 | 業界前輩，有機會內推 |
| 志工 | 免費 | 心情 ↑ | 各種人 |
| 同學會 | — | 由事件觸發，不能自選 | 老同學，可能重逢舊情 |

每次參加活動都會依「可能遇到」的類型擲骰，有機率產生新的 NPC。

### 9.3 NPC 與人脈

同事、朋友、戀愛對象都是同一種 NPC 資料結構：

| 欄位 | 說明 |
|---|---|
| 姓名、年齡、性別 | 隨機產生，使用台灣常見姓名 |
| 產業、職位 | 影響能否內推 |
| 個性 | 從清單中抽 2 項（例如：直率、慢熱、愛玩、上進、顧家） |
| 興趣 | 1～2 項，與活動類型對應 |
| 好感度 | 0～100，久未互動會緩慢下降 |
| 關係 | 認識 → 朋友 → 好友；或 認識 → 曖昧 → 交往 |

「人脈數值」等於好感度達到朋友以上的 NPC 數量。

### 9.4 戀愛（v0.5）

- 開局時設定戀愛偏好：異性／同性／都可以／不談戀愛
- 關係階段：認識 → 曖昧（好感 ≥ 50，觸發告白事件）→ 交往
- 交往後每週需要安排約會時段，否則好感下降
- 工作和戀愛會互相影響：連續加班會觸發「你是不是比較愛工作」事件；交往中心情每日小幅回升
- 個性會影響互動：上進型對象喜歡你進修，顧家型對象在意你加班
- 分手會讓心情大幅下降，好感歸零，但不會刪除 NPC
- 結婚、同居、生子留到 v0.6 之後

## 10. 事件系統

### 10.1 事件資料格式

事件全部放在 `src/data/events.js`，邏輯程式不寫死任何事件。

```js
{
  id: 'line_at_midnight',
  title: '深夜的 LINE',
  text: '晚上 11 點，主管在工作群組 @ 你：「明天早上要的資料好了嗎？」',
  type: 'minor',                 // minor：一般事件 | major：重大抉擇
  condition: s => s.job != null, // 觸發條件
  weight: 10,                    // 抽選權重
  cooldownDays: 30,              // 冷卻天數
  choices: [
    { text: '馬上回覆並開電腦', effects: { performance: +5, energy: -10, mood: -10 } },
    { text: '已讀，明天再說', effects: { mood: -3 }, chance: { p: 0.3, then: 'boss_unhappy' } },
    { text: '裝作沒看到',     effects: { performance: -5, mood: +5 }, default: true },
  ],
}
```

- `effects`：直接改數值
- `chance`：機率觸發後續事件，用來做事件鏈
- `default: true`：離線時自動選這個

### 10.2 事件分類

| 類型 | 離線時 | 範例 |
|---|---|---|
| 一般事件 | 自動套用預設選項 | 同事請吃飯、深夜 LINE |
| 重大抉擇 | 暫停時間，等玩家回來 | 升遷要不要接受、被挖角、告白、裸辭 |

觸發方式：每個遊戲日依權重擲骰一次，平均每週 1～2 個事件；另外也有固定日期事件，例如年度考核、尾牙、年終。

### 10.3 v0.1 事件清單（10 個）

| ID | 事件 | 選擇摘要 |
|---|---|---|
| line_at_midnight | 深夜主管 LINE | 馬上回／已讀不回／裝死 |
| simple_change | 「簡單改一下就好」 | 熬夜改／協商時程 |
| coworker_quit | 同事離職，工作分給你 | 接下／婉拒 |
| lunch_invite | 同事揪午餐 | 去（花錢、好感 ↑）／自己吃 |
| year_end_bonus | 年終只有 1 個月 | 忍／開始投履歷（v0.3 前僅影響心情） |
| boss_blame | 主管把錯推給你 | 吞下去／據理力爭 |
| sick_day | 好像感冒了 | 請病假／硬撐上班 |
| friday_drink | 週五下班有人揪 | 去（心情 ↑、明天體力 ↓）／回家 |
| new_project | 被指派新專案 | 接（表現 ↑↑、強制加班 2 週）／推掉 |
| salary_day_shopping | 發薪日看到想買的東西 | 買（心情 ↑、存款 ↓）／忍住 |

## 11. 財務

| 項目 | 規則（初始值） |
|---|---|
| 起始存款 | 3 萬 |
| 起薪 | 3.2 萬／月（專員） |
| 生活費 | 每月固定扣 1.8 萬（含房租），隨年齡與生活階段調整 |
| 加班費 | 每格加班時段 = 日薪 × 0.5（部分產業為責任制，沒有加班費） |
| 投資（v0.4） | 定存：年利率 1.5%；ETF：年化報酬期望 6%，每年隨機波動 ±15% |
| 買房（v0.6+） | 頭期款 + 房貸，生活費結構改變 |

**被動收入**等於投資每月平均收益。當被動收入大於等於生活費時，解鎖「財富自由」結局選項。

## 12. 結局與回顧

| 結局 | 條件 |
|---|---|
| 退休 | 65 歲自動觸發，是一般結局 |
| 財富自由 | 被動收入 ≥ 生活費時可選擇提早退休 |
| 爬到頂 | 升上總經理時可選擇「功成身退」 |
| 出走 | 存款達門檻時可選擇離開職場去開店、環島或出國（v0.4+） |
| 過勞 | 一年內病倒 3 次，強制住院，之後可選擇繼續或重新開始 |

### 12.1 職涯回顧卡

結局時產生一張可以截圖分享的卡片：

- 工作年數、加班總時數、換過幾份工作、最高職位
- 學過的課程與證照
- 最好的朋友、伴侶
- 最後存款或資產
- 一句人生總結，依數值組合產生，例如「工作 32 年、加班 4,821 小時，最後在宜蘭開了民宿」

## 14. 技術架構

### 14.1 技術選擇

| 項目 | 選擇 | 理由 |
|---|---|---|
| 前端 | HTML + CSS + 原生 JS（ES modules） | 不需要 build，AI 協作與除錯都直接 |
| 存檔 | localStorage | 不需要後端 |
| 離線與安裝 | PWA（manifest + service worker） | 可加入主畫面、離線遊玩 |
| 部署 | Cloudflare Pages 或 GitHub Pages | 靜態網站，免費 |

### 14.3 遊戲迴圈

```
每秒執行一次：
  經過的真實毫秒 = 現在 − 上次結算時間
  要推進的遊戲日 = floor(經過毫秒 × 速度 / 10000)
  逐日呼叫 advanceDay(state)：
    1. 套用當天時段活動
    2. 上班與薪水結算
    3. 數值門檻檢查
    4. 擲事件；若為重大抉擇 → 暫停並跳出
    5. 固定日期事件（月結、年度考核）
  更新畫面
```

- 離線推進與線上推進共用 `advanceDay`，只差在離線有 12 週上限，且事件自動選預設
- 系統模組只修改 `state`，不直接操作 DOM；UI 依 `state` 重繪
- 亂數可以指定種子，方便重現 bug

### 14.4 存檔

```js
{
  version: 1,
  savedAt: 1792000000000,  // 真實時間，用於計算離線時長
  seed: 12345,
  state: { ... }
}
```

- 每 10 秒自動存檔，切到背景（`visibilitychange`）時也立即存檔
- 讀檔時若 `version` 較舊，依序執行遷移函式升級到最新格式
- 選單提供「匯出存檔碼」（base64 字串），用來換手機或防止瀏覽器清除資料

### 14.5 PWA 注意事項

- iOS 需要 16.4 以上，而且必須先「加入主畫面」才能收到推播；推播 v0.1 不做
- service worker 採 cache-first；每次發版要更新快取版本號，否則玩家會一直拿到舊檔
- iOS Safari 長時間沒開啟時，可能清除 localStorage，所以匯出存檔碼是必要功能

## 15. 開發路線圖

每一版都必須**本身就能完整遊玩**。驗收通過、實際玩過覺得好玩，才開始做下一版。

### v0.1 放置手感驗證

- 上班自動賺錢，存款即時跳動
- 體力、心情、工作表現三個數值
- 每週行程只有「休息」和「加班」兩種
- 年度考核與升遷（通用職位階梯）
- 10 個一般事件（§10.3）
- 離線推進與「你不在的時候」摘要
- 存檔、匯出匯入存檔碼
- PWA 可加入主畫面

**驗收**：手機上玩 3 天，每天打開 3～5 次，感覺「回來看看」有期待感。

### v0.2 時間分配

- 行程加入耍廢、進修、運動
- 課程系統（3～5 門課）
- 技能數值開始影響升遷
- 事件擴充到 25 個，加入重大抉擇類型

**驗收**：會為了「這週要不要上課」猶豫，代表時間開始稀缺了。

### v0.3 轉職

- 3～4 種產業
- 職缺板、求職流程、面試事件
- 年齡門檻、裸辭

**驗收**：至少玩出兩條明顯不同的職涯路線。

### v0.4 活動與人脈

- 參加活動、NPC 產生、好感度
- 內推、副業、投資
- 人際分頁
- 出走結局

**驗收**：至少有一次轉職是靠人脈達成的。

### v0.5 戀愛

- 戀愛偏好、曖昧、告白、交往、分手
- 工作與戀愛互相影響的事件
- 職涯回顧卡

**驗收**：完整跑完一輪人生，並產生回顧卡。

### v0.6 之後（未排定）

結婚與生子、買房、通膨、多城市、成就系統、雲端存檔、推播通知、App Store 上架。
